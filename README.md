# My Daily Journal

A responsive personal routine journal, habit tracker, and trading log made with plain HTML, CSS, and JavaScript.

## Run it
1. Extract the ZIP file.
2. Open `index.html` in your browser.

## Publish with GitHub Pages
1. Create a new repository on GitHub.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages** in the repository.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose the `main` branch and `/(root)`, then save.
6. Wait for GitHub to publish the website and open the URL it provides.

## Data and privacy
- Data is saved in the current browser using `localStorage`.
- Data does not automatically sync across devices or browsers.
- Use **History & backup → Export backup** to save a JSON backup.
- Importing a backup replaces data currently saved in that browser.
- Clearing browser site data can delete your journal, so export backups regularly.

## Features
- Daily goals, accomplishments, reflection, mood, and tomorrow's first action
- Editable habit list with daily check-offs and completion percentage
- Trading log with pair, session, direction, entry, stop loss, take profit, P/L, risk, emotions, and rule-following
- Daily trade count, win rate, net P/L, and discipline percentage
- Date selector, saved history, JSON export/import
